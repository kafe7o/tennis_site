# Мъже (ATP) - файлове от tennis-data.co.uk

Качи тук годишните файлове за мъжете (`2019.xlsx`, `2020.xlsx`, ... `2025.xlsx`) от
http://www.tennis-data.co.uk/alldata.php (раздел ATP). Имената не се променят.

Достатъчни са последните 6-7 години: първите 3 са за обучение, останалите - за проверка срещу пазара.
Пускане: `cd pipeline && python run.py backtest --data ../data`
